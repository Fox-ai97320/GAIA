Paramètres

Le serveur doit accepter POST JSON {message, agent} et renvoyer {reply}. Ne saisissez jamais une clé API secrète ici : ce site est public.

Aide

Installer : dans Chrome Android, ouvrez le menu ⋮ puis « Ajouter à l'écran d'accueil ».

Voix : la dictée dépend de votre navigateur et des permissions micro. La lecture utilise la synthèse vocale disponible.

IA : les réponses avancées nécessitent un serveur HTTPS sécurisé, indépendant de GitHub Pages.

Sécurité : aucune clé privée ne doit être placée dans ce site public.
